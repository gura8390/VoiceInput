# 语音输入 0.6.0

发布日期：2026 年 11 月 17 日。本次公开源码及 `v0.6.0` 标签。此前单入口和内存研究使用的内部 1.0.0／1.0.1 编号统一归入 0.6.0，原始记录继续使用当时的构建哈希。

## 本版内容

- 保留实时听写、热词、音视频文件转录三个功能，统一为带中文产品信息和图标的 `语音输入.exe`。
- 保留托盘操作，补齐 DPI 感知和面向 AI 的 JSON 自动化接口，不增加主窗口或设置窗口。
- 采用 `config/`、`runtime/` 的单一运行布局，移除旧双启动入口及旧路径搜索。
- 默认 Qwen3-ASR 1.7B，0.6B 可选；编码权重外置、动态 ASR 上下文、独立闲置释放和有界 Vulkan 权重上传降低相应阶段内存。
- 模型包缺件或空权重在原生加载前检查；文件任务立即报告加载错误，实时听写继续保留 PCM 重试。
- 保存全部已采用和未采用的研究结论。具体模型、口径、范围及不利值见 [内存报告](../memory-optimization.md) 和 [优化历史](../optimization-history.md)。

## 构建与使用边界

本次没有新增可下载的程序 Release 包；GitHub 标签下的自动归档是源码。构建与依赖准备按 [README](../../README.md) 执行，个人配置、热词、录音、模型、运行库及本机证据不上传。

旧 0.4.5 的双入口和 `core/server` 布局应按 [目录说明](../layout.md) 显式迁移，不能把新 EXE 直接覆盖到旧运行布局使用。模型需先通过 `tools/models/prepare_external_weights.py` 在独立目录生成配套 `.weights.bin` 并校验，再连同 ONNX 一起安装。模型数值与量化保持，原件先备份。
