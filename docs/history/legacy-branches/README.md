## 模型、版本与测量边界

这些是 2026 年 10 月 27 日的旧版实验。CPU 与调度研究使用 Qwen3-ASR 0.6B 的 INT4 编码权重 / FP32 激活和 Q4_K Vulkan 解码；可选模型研究对比原 1.7B FP16 编码资产 / Q5_K_M 解码。它们不使用后来 1.7B 的 GGML GPU 编码器。

本次只是查阅和整理既有记录，没有重新跑性能或识别测试。主机私有提交、工作集及 GPU 阶段读数分别统计，文件独立 PCM 请求与实际媒体导出分别说明。固定样本精确回归不写作人工识别正确率；缺少逐字稿的旧组没有补写 CER / WER。

已经试过但不合适，与仅分析、未实现、未测量的方案，在各页分开列出。没有给未测量的 SameAsRequested arena、ORT 全局线程池或跨请求流水线捏造收益；后来的新模型或新后端应重新评估自己的瓶颈。
