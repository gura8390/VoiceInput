# 语音输入使用说明

0.6.0 版本保留实时听写、热词、音视频文件转录。双击 `语音输入.exe` 后在系统托盘运行；没有新增主窗口或设置窗口。

## 实时听写

按住 CapsLock 录音，松开后识别并输入到当前编辑位置。托盘菜单显示当前状态。模型在需要时加载，闲置后释放工作进程。当前安装默认使用 Qwen3-ASR 1.7B，0.6B 仍可通过配置或模型快捷方式选择。

## 热词

托盘右键选择“编辑热词”，修改 `config/hot.txt`。发音变体和修正规则保存在 `config/hot-rule.txt`。现有热词引擎支持重新加载文件内容；编辑后保存文件。CapsWriter 和 Godot 的实际识别变体已纳入规则。规则可能会按用户选择修正有歧义的独立英文词，完整英文句子的上下文保护仍保留。

## 文件转录

托盘右键选择“转录音频 / 视频…”，在系统文件选择对话框中选择文件。完成后在原文件旁生成 TXT、JSON 和 SRT。原始媒体不改写；同名输出按程序原有行为处理，重要既有输出请先保留副本。命令行可通过 `transcribe` 和 `--output-dir` 指定独立输出位置。

## 配置与 AI 操作

配置位于 `config/settings.json`。配置中的 `app_dir` 相对配置文件目录解析，本安装使用 `..`。手动修改模型或运行参数后重新启动。详细的机器可读状态、配置读写、热词检查、自启动注册和退出命令参见 [AI 自动化接口](ai-automation.md)。启动项仍指向同一个正式 EXE，读取当前保存的模型配置。

## 排查与退出

托盘“退出”会结束应用及其模型工作进程。错误与当前运行日志位于 `logs/rust-worker.log`；过大的日志自动轮换。每个编码 ONNX 的配套 `.weights.bin` 须与其放在同一模型目录。移动依赖或缺少模型会导致功能失败，应按 [目录说明](layout.md) 核对。当前数据见 [持续内存优化报告](memory-optimization.md)，历次实验见 [优化历史](optimization-history.md)。
